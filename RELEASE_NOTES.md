## Touhou 6 — 1.02h (September 2026 update)

* 🌏 **Proper name in hbmenu:** `東方紅魔郷　～ the Embodiment of Scarlet Devil` on consoles set to 日本語, `Touhou 6: the Embodiment of Scarlet Devil` everywhere else, with **ZUN / Team Shanghai Alice** as the author — like the other Touhou ports.
* 📁 **One folder for all Touhou ports.** Recommended folder: `sd:/switch/touhou/touhou6/` — keep every Touhou port in one `sd:/switch/touhou/` folder instead of separate folders. The NRO's own folder is always checked first, and the old locations still work.
* 🎮 **Controls like the other Touhou ports:** ZL/ZR now act as L/R, Key Config's **Default** restores the Switch layout (it used to reset to the PC one, with no pause button), and the D-Pad keeps moving whatever you rebind. The default layout is the same as every other port (B shoot, A bomb, L/ZL focus, R/ZR skip, + pause); the D-Pad and sticks only move.
* Gameplay itself is unchanged — just replace `touhou6.nro`.
